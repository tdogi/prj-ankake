# Project Ankake プレイヤーガイド

## はじめに

Project Ankake は、クリーチャーを盤面で進軍させ、CPUの拠点や中立拠点を奪い合う対戦型デジタルカードゲームです。攻撃は自動で行われるため、クリーチャーをどこに召喚・移動させるかが重要になります。

カードはクリーチャーとスペルの2種類です。クリーチャーは盤面に出して戦い、スペルは使うと効果を発揮します。

## 対戦を始める

1. メニューの **デッキ構築** を開きます。
2. デッキ名を入力し、カードを合計40枚になるよう追加して保存します。同名カードは4枚まで入れられます。
3. メニューの **CPU対戦** を開きます。
4. プレイヤー用とCPU用に、40枚の対戦可能なデッキをそれぞれ選びます。
5. 先攻・後攻を選び、**対戦開始** を押します。

デッキには火・水・風・光・闇のカードを自由に混ぜて入れられます。カードの詳細はデッキ構築画面で確認できます。

## 画面の見方と基本操作

- 画面上側がCPU、下側があなたです。
- 手札のカードを選び、光っているマスまたは対象を選択してプレイします。
- 自分のクリーチャーを選んでから行き先を選ぶと、移動できます。複数マス移動できる場合は、途中の経路を順に選びます。
- 確定前の召喚・移動・スペルは、操作パネルの取り消しで取りやめられます。移動中は「手順を戻す」も使えます。
- 行動を終えたら **プレイフェーズを終了** を押します。以降の攻撃処理は自動です。
- 右側の情報欄ではPP、手札・デッキ枚数、拠点HP、共鳴値、対戦ログを確認できます。

## 勝利条件

次のいずれかを満たすと勝利です。

- 敵プレイヤー拠点のHPを0にする。
- 3つすべての中立拠点を自分のものにする。
- 相手がデッキ切れになる。
- 相手がリタイアする。

## 盤面とレーン

盤面は11列×9行で、中央に3つの中立拠点、上下にプレイヤー拠点があります。画面下側があなたの初期陣地、上側がCPUの初期陣地です。一部の場所にはマスがないため、移動や召喚はできません。

列1～4が左レーン、5～7が中央レーン、8～11が右レーンです。レーンは共鳴効果と、一部カードの効果に関係します。

## ターンの流れ

ターンは次の順で進みます。

1. **スタンバイ**：PPが回復し、通常はカードを1枚引きます。ゲーム全体で最初のターンだけ、先攻はカードを引きません。
2. **プレイフェーズ**：カードの使用とクリーチャーの移動を、好きな順番で行います。
3. **アタックフェーズ**：ターンプレイヤーのクリーチャーが自動で攻撃します。その後、相手のターンです。

初期PPは1です。自分の2ターン目以降は、ターン開始時に最大PPが1ずつ増え、最大15まで上がります。使わなかったPPは次のターンに持ち越せません。手札の上限は9枚で、満杯のときに引いたカードは墓地へ送られます。

## 召喚と移動

### 召喚

クリーチャーは、自分の拠点に隣接する6マスに召喚できます。中立拠点を制圧している間は、その周囲8マスも召喚可能になります。

拠点そのもの、存在しないマス、すでにクリーチャーがいるマスには召喚できません。召喚したクリーチャーは、そのターンには通常移動できませんが、そのターンのアタックフェーズでは攻撃できます。

### 移動

通常の移動力は1です。自分のプレイフェーズ中、各クリーチャーは1回だけ移動できます。斜めを含む8方向に移動でき、特殊な能力で移動力が増えている場合は、1マスずつ方向を変えながら進めます。

ほかのクリーチャーがいるマスや拠点マスには入れず、通過もできません。移動にはPPを使いません。

## 自動攻撃とダメージ

アタックフェーズでは、ターンプレイヤーのクリーチャーが場に出た順に処理されます。各クリーチャーは周囲8マスにいる敵クリーチャーと攻撃可能な拠点を、すべて自動で攻撃します。

- 敵クリーチャーが優先して攻撃されます。
- 複数の対象がいても攻撃力は分割されず、それぞれに同じダメージを与えます。
- 攻撃を受けたクリーチャーは反撃しません。
- 体力が0になったクリーチャーは破壊され、墓地へ送られます。受けたダメージはターンをまたいで残ります。

## 拠点を制圧する

プレイヤー拠点の最大HPは20です。中立拠点は中央が20、左右が10です。

中立拠点のHPを0にしたプレイヤーが、その拠点を制圧します。制圧後はHPが最大まで回復し、所有中は周囲8マスを追加の召喚範囲として使えます。相手が所有する中立拠点も、HPを0にすれば直接奪い返せます。

## 属性と共鳴

カードには火・水・風・光・闇のいずれかの属性があります。各属性の共鳴値は、左・中央・右のレーンごとに別々に管理され、15になるとそのレーンで共鳴が有効になります。

- クリーチャーを手札から召喚すると、そのレーンの同属性共鳴値が増えます。
- スペルを手札から使うと、全レーンの同属性共鳴値がそれぞれ1増えます。
- クリーチャーの増加量は元のコストと同じです。共鳴値の上限は各属性・各レーンごとに15です。
- 共鳴値はターン開始時にも減少しません。

共鳴中は次の効果を得ます。

| 属性 | 共鳴効果 |
|---|---|
| 火 | そのレーンの味方クリーチャーの攻撃力が+1。 |
| 水 | 自分のターン中、そのレーンで最初に移動する味方クリーチャーの移動力が+1。 |
| 風 | 自分のターン中、そのレーンで最初に手札から召喚するクリーチャーのコストが1下がる（最低1）。 |
| 光 | 自分のアタックフェーズ後、そのレーンの味方クリーチャーと自分が所有する拠点を1回復する。プレイヤー拠点も、共鳴中のレーンごとに1回復する。 |
| 闇 | 各ターンに一度、そのレーンの味方クリーチャーが最初に破壊されると、同じマスに1/1/1の闇トークンを出す。 |

## ちょっとしたコツ

- 中立拠点を取ると前線近くへ新しいクリーチャーを召喚できるため、攻めや守りの起点になります。
- 攻撃は隣接する全対象に及ぶので、複数の敵や拠点に届く位置を意識すると有利です。
- 同じ属性を同じレーンに集めると共鳴を狙いやすくなります。スペルは全レーンの共鳴値を増やせます。
